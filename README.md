# 🚀 دليل وموسوعة المقابلات لمطور الـ Frontend (Frontend Interview Blueprint)

> **الترسانة الشاملة للأسئلة التقنية، المعمارية، ونماذج الكود والإجابات النموذجية لمطوري الواجهات الأمامية (Frontend Developers).**  
> *إعداد وتطوير: محمد خميس (Mohamed Khamis)*

---

## 🌟 مميزات المشروع (Features)

- 📚 **بنك أسئلة متكامل**: يغطي أكثر من 38 سؤالاً شاملاً مع الإجابات النموذجية باللغتين العربية والإنجليزية.
- 🗂 **تصنيفات تفاعلية**:
  - **JavaScript Core & Advanced**: (Closures, Event Loop, Promises, Scope, Prototypes...)
  - **React & Modern Hooks**: (Virtual DOM, Custom Hooks, Performance, Context, Reconciliation...)
  - **Next.js & SSR/SSG**: (App Router, Rendering Strategies, Server Actions, Caching...)
  - **TypeScript**: (Generics, Utility Types, Type vs Interface, Enums...)
  - **CSS, Styling & Web Performance**: (Flexbox/Grid, Core Web Vitals, Responsive Design...)
  - **System Design & Frontend Architecture**: (Microfrontends, State Management, Scalability...)
  - **Behavioral & Soft Skills**: (STAR Method, Conflict Resolution, Leadership...)
- ⚡ **أدوات وتفاعلية متقدمة**:
  - 🔍 **بحث فوري ذكي (Instant Search)** مع تظليل النتائج.
  - 🎯 **فلترة حسب مستوى الصعوبة** (مبتدئ / متوسط / متقدم) ومستوى الأهمية.
  - 📇 **وضع المذاكرة والبطاقات التفاعلية (Flashcards Mode)**.
  - 📋 **نسخ الكود بنقرة واحدة (One-click Code Copy)** مع إشعارات Toast سلسة.
  - 🌓 **دعم الوضع الليلي والنهاري (Dark / Light Theme)**.
  - 💾 **حفظ تقدم المذاكرة محلياً (Mastered Progress via LocalStorage)**.
  - 🖨 **دعم الطباعة والتصدير كـ PDF منسق بدقة**.

---

## 🛠 التقنيات المستخدمة (Tech Stack)

- **HTML5 & Semantic Markup** (دعم كامل للغة العربية `RTL` والإنجليزية).
- **Modern Vanilla CSS3**:
  - CSS Custom Properties (Variables)
  - Glassmorphism & Modern Gradients
  - Dark / Light Theme Tokens
  - Smooth Micro-animations & Transitions
- **Modern JavaScript (ES6+)**:
  - Modular code architecture
  - LocalStorage Persistence
  - Fuzzy-like Search & Filtering Engine
- **FontAwesome Icons & Google Fonts (Cairo + Outfit + Fira Code)**.

## 💻 طريقة التشغيل (Getting Started)

المشروع مبني بـ Vanilla Web Technologies ولا يحتاج إلى أدوات بناء معقدة.

### 1. الاستنساخ (Clone the repo):
```bash
git clone https://github.com/mohammedkhames792/frontend-interview-guide.git
cd frontend-interview-guide
```

### 2. الفتح والتشغيل (Run Locally):
- ببساطة قم بفتح ملف `index.html` في أي متصفح ويب حديث.
- أو عبر Live Server في VS Code / أي سيرفر محلي:
```bash
npx serve .
```
